# Bulgarian React Documentation – Glossary

This glossary records terminology decisions for consistency across the Bulgarian translation.

## Core Terms

| English | Bulgarian usage | Notes |
|---|---|---|
| Component | компонент | Translated |
| Function Component | функционален компонент | Translated |
| props | props | Keep as-is |
| state (React API) | state | Keep as-is |
| state (general concept) | състояние | Use in general context |
| hook | hook | Keep as-is |
| Render (React call) | рендер | Use for React component execution |
| Render (browser paint) | изобразяване | Use for actual drawing/painting |
| key (React) | key | Keep as-is |
| key (generic) | ключ | Generic meaning |
| ref | ref | Keep as-is |
| Context | контекст | Translated |
| Fragment | фрагмент | Translated |
| pure function | чиста функция | Use BG + (EN) on first mention |
| declarative | декларативен | Use BG + (EN) on first mention |
| imperative | императивен | Use BG + (EN) on first mention |
| single source of truth | единствен източник на истина | Prefer BG + (EN) on first mention |

## Notes
- API names (e.g. `useEffect`, `useState`) are not translated.
- Add new terms here as decisions are made.
