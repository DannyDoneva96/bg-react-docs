
# Bulgarian React Documentation Translation

This repository contains draft materials, style guidelines, and terminology decisions for the Bulgarian translation of the official React documentation.

The goal of this project is to create a technically accurate, natural-sounding Bulgarian version of react.dev while preserving established React terminology.

## Status
- PR opened to start Bulgarian translation: reactjs/translations.react.dev#365
- Drafting style guide and glossary (this repo)
